INSTALL
1. Unzip this package.
2. Copy its contents into the ROOT of your existing oldtimepreaching GitHub folder (the same folder as the homepage index.html).
3. If prompted, choose Replace for the matching files. Do NOT put this folder inside another oldtimepreaching folder.
4. GitHub Desktop: commit changes and Push origin. Allow Cloudflare Pages to deploy.
5. Visit / and /articles/ezekiel-23-20-meaning/ and hard refresh (Ctrl+Shift+R).
